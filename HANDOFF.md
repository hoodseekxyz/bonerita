## Teknik

TanStack Start, React 19, Tailwind v4, Vite, Nitro. Vercel'e prebuilt basılır. Önizleme `127.0.0.1:8080`, `startup.sh` ile kalkar.

Yerel yayın, bu klasör bonerita projesine bağlıysa:

```bash
npm run build
npx vercel deploy --prebuilt --prod --yes --scope telefork
```

Anahtar ortamda `VERCEL_TOKEN`. Proje adı komutta değil, `.vercel/project.json` içinde. Yeni klasörde link yoksa önce `bonerita`'ya bağla, `headacheonlong`'a değil.

GitHub hesabı `hoodseekxyz`. Remote temiz, token URL'de değil.

`@tanstack/react-start` 1.168.60 altında kalmasın. Vercel bunu güvenlik diye geri çeviriyor.
